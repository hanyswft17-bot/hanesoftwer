HANI SOFTWARE — النسخة التصميمية الأولى
=======================================

المحتويات:
- واجهة عربية متجاوبة للهاتف والكمبيوتر.
- الصفحة الرئيسية والأقسام وصفحات تفاصيل الخدمات.
- واجهات تسجيل الدخول وإنشاء الحساب.
- لوحة العميل والطلبات وشحن الرصيد.
- تصور أولي للوحة الإدارة.
- ملف SQL تأسيسي آمن نسبياً للاستخدام مع Supabase Auth مرفق منفصلاً.

طريقة المعاينة:
1) فك ضغط الملف.
2) افتح index.html في المتصفح أو ارفع المجلد إلى GitHub Pages.
3) تنقل بين الصفحات والأقسام والخدمات.

تنبيه مهم:
هذه نسخة تصميم ومعاينة فقط، وليست منصة جاهزة لاستقبال أموال أو بيانات عملاء حقيقية.
نماذج الدخول والطلبات والشحن لا تحفظ بيانات حقيقية ولا تنفذ خصماً من المحفظة.
صفحة الإدارة للعرض فقط وليست محمية في هذه النسخة.
لا تضع مفاتيح Supabase السرية أو service_role داخل JavaScript أو ملفات المتصفح.

الربط الحقيقي:
يحتاج إعداد Supabase Auth، وجداول بقاعدة البيانات، وسياسات RLS، ودوال خادمية
لإنشاء الطلب وخصم الرصيد بشكل ذري، ثم ربط الواجهة بمشروع Supabase.
